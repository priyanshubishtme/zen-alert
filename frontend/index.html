How ZenAlert Works

From physical sensor readings to verified incident alerts — a four-stage pipeline with zero cloud dependency.

01

Multi-Sensor Data Ingestion

ESP32-S3 nodes collect continuous analog and digital streams from an array of environmental sensors (MQ135, MQ2, DHT11, GP2Y1010). Data is buffered locally, filtered for noise, and packaged into lightweight binary payloads for efficient transmission.

  • Dynamic sampling rates based on battery SOC.
  • Local calibration offsets applied.
  • Image capture (IMX219) triggered only upon sensor anomaly.

02

Edge Inference & Multi-Modal Verification

NVIDIA Jetson Nano acts as the local cluster gateway. It runs YOLOv8 for visual object detection (fire/smoke) and a CNN-LSTM model for sensor time-series forecasting. The results are fused into a single confidence score.

  • Zero cloud dependency for inference.
  • Multi-modal fusion prevents false positives.
03

Long-Range Off-Grid Transmission

Using LoRa (SX1278) modules, sensor nodes transmit data over a multi-kilometer radius to the edge gateway without cellular or Wi-Fi infrastructure. A self-healing mesh topology ensures packets reach the gateway even if a node goes offline.

04

Alert Generation & Mapping

Verified incidents are pushed via FastAPI to the MapLibre GL JS dashboard. District authorities see real-time GIS mapping of the threat radius and can instantly dispatch SMS, Push, and local Siren alerts.
